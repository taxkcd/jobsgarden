## The role

The Senior Backend Engineer (Full Stack) at PackageX is responsible for building and scaling backend services, APIs, and integrations that handle large volumes of data from logistics environments, as well as developing full-stack web features including dashboards and configuration tools.

Responsibilities:
- Design and build the backend services and APIs that power the PackageX platform, mobile app, and web console.
- Model data for complex, configurable workflows and maintain consistency as volume grows.
- Build and maintain integrations with customer ERPs, WMSs, TMSs, third-party APIs, webhooks, and data exports.
- Write event-driven and async processing with queues, workers, and scheduled jobs.
- Build the backend behind Vision AI features, image ingestion, processing pipelines, and result storage, collaborating with the AI team.
- Handle offline sync and conflict resolution for data from mobile devices.
- Build web features end to end, from API to UI using React and Svelte.
- Find and fix slow queries, bottlenecks, and reliability issues.
- Own services in production including deploys, monitoring, logging, alerting, on-call, and post-incident fixes.
- Keep the platform secure with access control and multi-tenant data isolation.
- Write tests, review code, and maintain design docs and API documentation.
- Join implementation and customer conversations for integrations and data issues.

Requirements (required):
- 5+ years building and running production backend services.
- Strong in Node.js/TypeScript, Python, or Go.
- Knowledge of relational databases: schema design, indexing, query tuning, migrations (MySQL and PostgreSQL).
- Experience designing APIs and building integrations with third-party or enterprise systems.
- Experience with queues and async processing (SQS, RabbitMQ, Kafka, or similar).
- Experience deploying and running services on AWS or GCP, with Docker and CI/CD pipelines.
- Hands-on React experience and ability to ship production-ready web features independently.
- Comfortable owning a feature from database schema to UI.
- Comfortable working both backend-first and full stack.

Requirements (preferred):
- Experience integrating with ERP, WMS, TMS, or other logistics and enterprise systems.
- Experience with image pipelines, ML-backed products, or mobile backends with offline sync.
- Experience building or running multi-tenant SaaS platforms.
- Experience in logistics, supply chain, manufacturing, warehousing, or operations-heavy domains.
- Experience with Svelte or confidence picking it up quickly.

Team and product context: Works with product, mobile, AI, and implementation teams; owns services in production and participates in customer integrations and implementation conversations.

Work model, location, authorization: On-site job openings in Islamabad, Pakistan; no explicit remote or visa statements in posting.

Compensation: not stated
