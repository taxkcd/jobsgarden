## The role

The Data API Engineer role at Supabase involves improving the feature set, reliability, and performance of their Data API based on the PostgREST project, working on PostgreSQL drivers, new features, bug fixes, incident resolution, and cross-team collaboration.

Responsibilities:
- Work on PostgREST’s PostgreSQL driver (based on Hasql) and remove bottlenecks and improve its performance.
- Work on PostgREST development of new features and bug fixes, aligned towards the goal of a multitenant Data API.
- Resolve incidents and escalated support issues, while also improving observability and performance.
- Collaborate cross-functionally with other teams to debug and solve integration issues with the Supabase platform.

Requirements (required):
- Strong Haskell skills with at least 3 years of experience.
- Experience using the C language.
- Solid knowledge of SQL and plpgsql scripting in PostgreSQL.
- Strong track record of contributing to and engaging with open-source projects. Bonus points if you’ve maintained an open source project.
- Strong experience with providing technical support to users with varying levels of technical expertise.
- Experience with debugging applications under the Linux operating system.

Requirements (preferred):
- none stated

Team and product context: Data API Team focused on PostgREST and building developer tools that scale to millions; Supabase is a globally distributed, open-source-first company with ~400 team members across 60+ countries.

Work model, location, authorization: Fully Remote; Supabase hires globally with no offices but provides WeWork membership or co-working allowance; operates asynchronously with flexible work hours.

Compensation: ESOP (equity ownership), tech allowance, health benefits covering 100% employee and 80% dependents globally, annual off-sites, professional development allowance.
