## The role

The role is for a Software Engineer with 2+ years experience in Machine Learning and Computer Vision to develop real-time AI assistance for clinicians using ultrasound video analysis in a health tech project.

Responsibilities:
- Train and improve multi label medical image segmentation models using PyTorch
- Work with ultrasound video datasets and clinician annotated medical imaging data
- Run experiments around class imbalance, overlapping anatomy, small or thin targets, and temporal context
- Build and improve evaluation pipelines with per label, frame level, and event level metrics
- Validate models using patient level test splits and clinician review
- Optimize inference for real time video processing with a focus on GPU latency and performance
- Work with mixed precision, model compilation, batching, frame stride, and other inference optimization techniques
- Package and deploy models using Docker and AWS based infrastructure
- Contribute to reproducible training and retraining pipelines with experiment tracking, checkpointing, CI, and automated testing
- Collaborate with clinicians, annotators, infrastructure engineers, and external ML partners
- Participate in regular client calls, technical discussions, demos, requirement discussions, and progress updates
- Explain technical decisions, experiment results, risks, and tradeoffs clearly to both technical and non technical stakeholders
- Work directly with the client to understand feedback, clarify requirements, and translate discussions into actionable engineering tasks

Requirements (required):
- 2+ years of relevant software engineering, Machine Learning, or Computer Vision experience
- Strong Python programming skills
- Hands on experience with PyTorch
- Experience training image segmentation or Computer Vision models
- Understanding of model training, validation, evaluation, and inference workflows
- Familiarity with data loaders, mixed precision training, checkpointing, and GPU based training
- Understanding of video or image based datasets and good practices around train and test data separation
- Experience or familiarity with AWS, cloud GPU environments, object storage, and Docker
- Understanding of production ML inference and performance optimization
- Strong software engineering fundamentals including testing, version control, reproducible configurations, and CI
- Strong verbal and written communication skills
- Confidence participating in client meetings and technical discussions
- Ability to explain technical topics clearly, ask the right questions, and communicate blockers or risks proactively
- Ability to discuss experiments, model results, implementation decisions, and tradeoffs directly with the client

Requirements (preferred):
- Experience with medical imaging or medical image segmentation
- Experience with medical video annotation platforms
- Real time Computer Vision or video inference experience
- Familiarity with multiple segmentation architectures or frameworks
- Experience working with multi GPU training
- Knowledge of model deployment and inference optimization
- Previous experience working directly with clients, product teams, or external stakeholders
- Awareness of Software as a Medical Device practices, model traceability, model cards, audit trails, or clinical acceptance processes

Team and product context: not stated
